# 本地启动说明

## 环境要求

- Windows 10/11
- Python 3.10 或更高版本
- Chrome 或 Edge
- 可访问 DeepSeek API 的网络

## 操作步骤

### 方法一：双击启动（推荐）

1. 下载并完整解压 `Agent-TA` 文件夹。
2. 双击根目录的 `启动小蜜蜂.bat`。
3. 首次运行会自动复制 `.env.example` 为 `.env` 并打开记事本。
4. 在 `.env` 中填写自己的 `DEEPSEEK_API_KEY`，保存并关闭记事本。
5. 再次双击 `启动小蜜蜂.bat`。程序会检查 Python 和依赖，启动后自动打开浏览器。
6. 使用结束后双击 `停止小蜜蜂.bat`。

### 方法二：命令行启动

1. 下载仓库 ZIP 并解压，或执行：

   ```powershell
   git clone https://github.com/hejie0034/Agent-TA.git
   cd Agent-TA
   ```

2. 安装依赖：

   ```powershell
   python -m pip install -r requirements.txt
   ```

3. 复制配置示例：

   ```powershell
   Copy-Item .env.example .env
   ```

4. 编辑 `.env`，填写接收方自己的 DeepSeek API Key。

5. 启动服务：

   ```powershell
   python web_agent.py --port 8012
   ```

6. 浏览器打开 <http://127.0.0.1:8012>。

7. 打开 <http://127.0.0.1:8012/api/health>，确认 `ok` 和 `configured` 均为 `true`，并核对 FAQ 为 288 条、截图教程为 96 组、视频教程为 29 个。

## 停止与重启

命令行启动时，在服务终端按 `Ctrl + C` 停止；双击启动时，运行 `停止小蜜蜂.bat`。修改 `.env`、Python 代码或知识库后，应停止并重新启动服务。
