# 本地启动说明

## 环境要求

- Windows 10/11
- Python 3.10 或更高版本
- Chrome 或 Edge
- 可访问 DeepSeek API 的网络

## 操作步骤

1. 下载仓库 ZIP 并解压，或执行：

   ```powershell
   git clone https://github.com/hejie0034/Agent-TA.git
   cd Agent-TA
   ```

2. 安装依赖：

   ```powershell
   python -m pip install -r requirements.txt
   ```

3. 复制配置示例：

   ```powershell
   Copy-Item .env.example .env
   ```

4. 编辑 `.env`，填写接收方自己的 DeepSeek API Key。

5. 启动服务：

   ```powershell
   python web_agent.py --port 8012
   ```

6. 浏览器打开 <http://127.0.0.1:8012>。

7. 打开 <http://127.0.0.1:8012/api/health>，确认 `ok` 和 `configured` 均为 `true`。

## 停止与重启

在服务终端按 `Ctrl + C` 停止。修改 `.env`、Python 代码或知识库后，应停止并重新启动服务。
