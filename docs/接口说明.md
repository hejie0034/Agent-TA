# 接口说明

## 本项目接口

### `GET /api/health`

用于检查服务、API Key 配置和知识库加载状态。重点字段：

- `ok`：服务是否正常
- `configured`：是否读取到 API Key
- `model`：当前配置的模型
- `faqCount`：已加载 FAQ 数量

### `POST /api/chat`

供本项目前端提交教师操作问题。请求和返回格式以 `web_agent.py` 当前实现为准；前端不直接调用第三方模型。

## 第三方 AI 接口

- 服务商：DeepSeek（深度求索）
- 基础地址：`https://api.deepseek.com/v1`
- 请求：`POST /chat/completions`
- 默认模型：`deepseek-chat`
- 鉴权：`Authorization: Bearer <DEEPSEEK_API_KEY>`
- 格式：OpenAI 兼容的 Chat Completions JSON

“OpenAI 兼容格式”只表示请求结构兼容，不表示项目使用 OpenAI 模型或 OpenAI API Key。

## 环境变量

| 变量 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `DEEPSEEK_API_KEY` | 是 | 无 | DeepSeek API 密钥 |
| `DEEPSEEK_BASE_URL` | 否 | `https://api.deepseek.com/v1` | DeepSeek API 基础地址 |
| `DEEPSEEK_MODEL` | 否 | `deepseek-chat` | 模型名称 |
| `PORT` | 否 | `8012` | 本地服务端口 |

旧版的 `ULEARNING_TEACHER_ASSISTANT_API_KEY` 仍可兼容读取，但新交付统一使用 `DEEPSEEK_API_KEY`。
