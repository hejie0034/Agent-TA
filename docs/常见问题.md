# 常见问题

## 项目使用的是哪家的 AI？

使用 DeepSeek（深度求索）官方 API，默认模型是 `deepseek-chat`。代码采用 OpenAI 兼容的请求格式，但没有使用 OpenAI 模型。

## API Key 在哪里申请？

由接收方在 DeepSeek 官方平台申请。交付方不在 GitHub 中提供或代填真实密钥。

## 没有 API Key 能否运行？

页面和部分本地知识库逻辑仍可加载，但完整的 AI 回答整理能力不可用。

## 网页打不开怎么办？

确认 Python 服务窗口仍在运行，并使用启动时显示的端口。默认访问 <http://127.0.0.1:8012>。

## `configured` 是 `false` 怎么办？

确认 `.env` 与 `web_agent.py` 位于同一目录，变量名为 `DEEPSEEK_API_KEY`，等号后有有效密钥，并在修改后重启服务。

## 提示缺少 `openpyxl` 怎么办？

运行：

```powershell
python -m pip install -r requirements.txt
```

## 能否让同事从另一台电脑访问？

当前默认不能，因为服务只监听本机地址。跨机器访问属于服务器部署，需要先完成网络、安全、访问控制和 HTTPS 配置。
