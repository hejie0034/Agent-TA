# 项目说明书

## 基本信息

- 项目名称：Agent-TA（AI 教师操作助手）
- 当前版本：V1.0.0
- 项目用途：帮助教师查询 uLearning / 优学院 Web 教师端操作步骤
- 使用对象：教师、教学支持人员、平台客服和项目维护人员

## 技术与 AI 信息

前端使用原生 HTML、CSS 和 JavaScript，后端使用 Python。后端先检索本地 FAQ、知识库切片和截图教程，再调用 **DeepSeek（深度求索）官方 API** 整理回答。

- 服务商：DeepSeek
- 默认模型：`deepseek-chat`
- 默认基础地址：`https://api.deepseek.com/v1`
- 调用路径：`/chat/completions`
- 鉴权变量：`DEEPSEEK_API_KEY`

项目没有把 API Key 写入前端，也不随交付包提供真实密钥。

## 已实现功能

1. 教师端操作问答
2. FAQ 和截图知识库检索
3. 相关问题推荐
4. 操作步骤截图展示
5. 点赞、点踩、未回答问题和转人工反馈记录
6. 服务健康状态检查

## 暂未实现

1. 自动点击或直接控制教师端
2. 用户账号和权限管理
3. 多机器共享的正式数据库
4. Docker 一键部署
5. 高可用、自动扩缩容和生产级监控

## 数据说明

知识库主要由 `ulearning_teacher_faq.json`、`切片读取知识库/`、`截图教程/` 和提示词文件组成。修改知识库后，应执行相应维护脚本并进行回归测试。反馈数据默认写入运行机器本地，正式部署前应确定访问权限、保存期限和备份方案。
