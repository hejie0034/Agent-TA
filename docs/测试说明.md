# 测试说明

## 启动验收

1. 在没有本项目环境的电脑上重新下载仓库。
2. 严格按照《本地启动说明》安装并启动。
3. 检查 `/api/health` 返回 `ok: true`、`configured: true`。
4. 确认页面、文字、图片和相关问题可以正常显示。

## 异常测试

- 不配置 API Key：页面仍可打开，健康检查应显示 `configured: false`
- 使用无效 API Key：不得泄露密钥，界面应给出可理解的失败提示
- DeepSeek 网络不可达：服务不得崩溃
- 端口被占用：更换 `--port` 后应能启动
- 输入知识库外问题：应提示边界或引导转人工

每次发布前记录测试日期、测试人、版本、实际结果、异常截图和处理结论。
