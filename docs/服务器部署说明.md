# 服务器部署说明

当前版本已适合本地交付和内部测试，但默认仅监听 `127.0.0.1`，不能直接作为公网生产服务。

## 推荐部署结构

```text
HTTPS 域名
  ↓
Nginx / 公司网关
  ↓
Python Agent-TA 服务
  ↓
DeepSeek API + 本地知识库
```

## 部署准备

- Python 3.10+
- 出站网络允许访问 `api.deepseek.com`
- 在服务器安全配置中设置 `DEEPSEEK_API_KEY`
- 使用独立的非管理员运行账号
- 由反向代理配置 HTTPS、访问日志和请求大小限制

## 注意事项

1. 不要把 `.env` 放入镜像、Git 仓库或公开下载目录。
2. 正式服务需将监听地址、跨域规则和反向代理配置纳入安全评审。
3. 建议使用 Windows Service、systemd 或受管容器保持进程运行。
4. 日志和反馈文件可能包含用户输入，应限制访问并制定清理周期。
5. 更新前备份知识库和反馈数据，更新后执行健康检查与测试用例。

当前仓库未提供 Docker、Nginx 或 systemd 成品配置。若要对外或跨机器开放，请由运维人员按公司规范补齐后再上线。
